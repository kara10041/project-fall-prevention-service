# 평면도 좌표 고정 + 수동 배치 전용 변경 (2026-08-19)

## AI BEFORE 이미지 구조 보존 강화
- 사용자 평면도 PNG를 계속 image edit 입력으로 사용합니다.
- 각 가구의 bbox 좌표를 방 크기 대비 정규화 좌표로 추가 전달합니다.
- 중심점, 크기, 회전, 벽 인접 여부를 HARD LOCK으로 프롬프트에 전달합니다.
- 각 가구의 가장 가까운 이웃과 상/하/좌/우 상대관계를 topology lock으로 추가했습니다.
- 중앙 조리대를 벽 쪽 일자 조리대로 합치거나, 냉장고/싱크대 등 주요 객체를 다른 구역으로 이동하는 것을 명시적 실패 조건으로 지정했습니다.
- BEFORE 이미지 기본 quality를 medium으로 올렸습니다. input_fidelity 기본값은 high입니다.

## 가구 배치 · AI 분석 페이지 단순화
- `AI에게 안전한 배치 추천받기` 모드를 UI에서 완전히 제거했습니다.
- 모드 선택 UI, AI 배치 입력 UI, AI 배치 결과 UI, 관련 JS 동작을 제거했습니다.
- `/api/generate_optimal_layout` 엔드포인트와 `optimal_layout_generator` 백엔드 모듈을 제거했습니다.
- 페이지는 이제 사용자가 직접 가구를 배치한 뒤 `현재 배치 안전성 점검하기`로 분석하는 단일 흐름만 제공합니다.
