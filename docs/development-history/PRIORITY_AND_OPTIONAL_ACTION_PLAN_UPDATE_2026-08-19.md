# 개선 우선순위 / Action Plan 선택 방식 수정 (2026-08-19)

## 1. 개선 우선순위 강조
- 공간 분석 결과의 개선 목록을 `1순위`, `2순위`, `3순위` 형태로 크게 표시합니다.
- 1순위는 배경/테두리/순위 배지를 더 강하게 강조합니다.
- Action Plan 카드에도 각 카드 상단에 `N순위` 배지를 표시합니다.
- 공간 단위 우선순위 화면에서도 1순위 배지의 대비를 강화했습니다.

## 2. Action Plan은 문제별 최대 1개 선택
- 기존: 각 문제마다 기본 대안 1개가 자동 선택되어 모든 문제를 반드시 선택하게 됨.
- 변경: 각 문제마다 0개 또는 1개를 선택할 수 있습니다.
- 같은 문제 안에서 다른 대안을 누르면 기존 선택은 자동 해제됩니다.
- 이미 선택한 대안을 다시 누르면 해당 문제를 미선택 상태로 되돌릴 수 있습니다.
- 전체적으로는 개선 전후 이미지를 만들기 위해 최소 1개의 개선 방법을 선택하도록 안내합니다.
- 서버도 미선택 항목을 0번 대안으로 강제 보정하지 않고 실제 선택 항목만 후속 이미지/PDF 흐름에 전달합니다.

## 3. 실시간 선택 합계
Action Plan 오른쪽에 `선택 요약` 패널을 추가했습니다.
- 선택한 항목 수
- 예상 총 소요시간
- 예상 총 비용 범위

선택/해제할 때마다 즉시 합산값이 갱신됩니다.
시간과 가격은 기존 각 실행계획의 추정치를 단순 합산한 참고값입니다.
