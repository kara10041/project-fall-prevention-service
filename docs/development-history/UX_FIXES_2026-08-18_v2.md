# UX / mapping fixes v2 (2026-08-18)

1. Point-note placement now captures pointer events before furniture drag/select, so notes can be placed directly on top of furniture.
2. Point notes now include the two nearest furniture names in backend spatial context; planner prompts explicitly require using relevant user notes to create location-specific, multi-step recommendations.
3. Internal IDs (`path_living_room_main`, `room_living_room_01`, `layout_object_*`) are sanitized globally for UI/PDF-facing text. Path IDs are rendered as e.g. `거실 주요 이동 동선`.
4. 3D view simplified: removed tiny furniture labels and height text, enlarged improvement markers, and restored side-by-side 2D/3D layout. 3D is explicitly a height/position reference; detailed names remain in 2D/list.
5. Photoreal reference generation now sends exact bbox/rotation/relative position in the prompt and, when supported by the installed OpenAI image API, uses the deterministic 2D floorplan PNG as an image-edit reference. Falls back to text-to-image if edit is unavailable.
