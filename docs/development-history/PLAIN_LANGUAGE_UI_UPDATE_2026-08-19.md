# 쉬운 말 UI 정리 (2026-08-19)

사용자에게 노출되는 화면 문구만 정리했습니다. 내부 변수명과 분석 로직(SHAP/RAG/hazard 등)은 변경하지 않았습니다.

## 주요 변경
- 전립선비대증 도움말을 초기 버전 문구인 `여성 또는 해당 없으면 체크하지 않습니다.`로 축약
- 설문 화면의 `calibrated RandomForest`, `독립변수` 등 연구/백엔드 표현 제거
- `독거 여부` → `혼자 거주 여부`, `교육연한` → `학교를 다닌 기간`, `완전 독립` → `혼자 할 수 있음`
- 결과 화면의 `모델 판정 기준`, `보정 확률`, raw SHAP 수치, `상호작용 영향도` 같은 기술 표현을 쉬운 말로 변경하거나 숨김
- 공간 점검 화면의 `SHAP`, `Hazard` 문구 제거
- 공간 우선순위 화면의 `SHAP × interaction × Hazard` 계산식 설명을 일반 사용자 설명으로 교체
- 가구 배치 화면의 `백엔드`, `SHAP`, `RAG`, `GPT`, `RAG 미매핑`, `근거 DB ID`, `문헌 근거 ID` 노출 제거
- 추가 확인 질문에서 hazard code 목록을 숨기고 `왜 확인하나요?`만 표시
- `Action Plan` → `실행 방법 고르기`, `PDF 리포트` → `PDF 보고서`
- 이미지 비교 화면의 `체크리스트`를 `공간 점검 답변`으로 변경

## 유지한 것
- 서버 내부 변수명, API 필드명, SHAP/RAG/hazard 계산 로직은 그대로 유지
- 기존 이미지 생성 및 좌표 고정 로직은 변경하지 않음
