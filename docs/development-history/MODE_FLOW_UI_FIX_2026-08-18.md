# 모드 분리 UI 개선 (2026-08-18)

## 핵심 변경
1. 상단을 `어떻게 진행할까요?` 선택 영역으로 재구성했습니다.
2. `내가 배치하고 안전성 점검` / `AI에게 안전한 배치 추천받기`의 목적을 명확히 구분했습니다.
3. 선택하지 않은 모드의 입력 UI는 숨깁니다.
4. AI 추천 모드의 진행 단계를 1~4로 명시했습니다.
   - 1 방 크기와 고정 구조
   - 2 필요한 가구와 배치 방식
   - 3 AI 배치 추천 생성
   - 4 추천 배치 안전성 최종 점검
5. AI 추천이 생성되기 전에는 `현재 배치 안전성 점검하기` 버튼을 숨깁니다.
6. AI 추천 생성 후에만 해당 점검 버튼을 노출하고, 직접 수정 후 검증하도록 안내합니다.
7. 버튼 문구를 `AI에게 안전한 배치 추천받기`, `현재 배치 안전성 점검하기`로 통일했습니다.
8. AI 모드에서는 오른쪽 편집 도구 제목을 `고정 구조 편집`으로 바꿔 역할을 명확히 했습니다.
