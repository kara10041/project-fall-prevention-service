# Before/After 이미지 프롬프트 업데이트 (2026-08-19)

- BEFORE: 사용자가 직접 만든 평면도를 authoritative reference로 사용해 같은 공간을 실사형 조감 이미지로 재현합니다.
- BEFORE에는 체크리스트에서 사용자가 확인한 위험, 방 전체 메모, 지점 메모를 현재 문제 상태로 반영하며 개선하지 않습니다.
- AFTER: 방금 생성한 BEFORE 이미지를 기준으로 같은 구조/카메라/가구를 최대한 유지하면서 선택된 개선안을 실제로 적용합니다.
- AFTER에는 변경 위치별 번호, 화살표/리더라인, 짧은 한글 설명, 색상 강조를 요청합니다.
- 추상적인 개선안은 먼저 텍스트 AI가 concrete visual command로 구체화하고 reason까지 포함한 뒤 이미지 모델에 전달합니다.
- PDF에는 생성된 AI BEFORE/AFTER 경로가 그대로 사용됩니다.
