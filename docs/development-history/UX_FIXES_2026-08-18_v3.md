# UX / result visualization fixes v3 (2026-08-18)

1. User free-text notes are no longer silently ignored when they are not mapped to a fall-risk hazard.
   - All room notes and point notes are preserved as a separate `사용자 추가 요청사항` section.
   - A separate AI space-layout answer is generated without changing the fall-risk priority ranking.
   - For placement questions such as "추가 수납장을 어디 둘지 모르겠다", the AI uses the measured layout and explicitly states when the available information is insufficient to choose a definitive position.

2. Removed the 3D comparison visualization from the user-facing result.
   - The measured 2D floorplan is now the single authoritative layout image.
   - Improvement numbers on the floorplan map directly to the numbered recommendations and the AI-generated reference image.

3. Photorealistic reference generation is now floorplan-first.
   - Uses the measured, numbered floorplan as the image-edit reference where supported.
   - Prompt changed from normal eye-level real-estate photography to a high bird's-eye / oblique realistic architectural visualization so the full layout can be compared side-by-side with the floorplan.
   - Explicitly forbids adding, omitting, or repositioning major furniture for composition.

4. PDF page 4 updated to the same model:
   - single authoritative 2D floorplan
   - mapped realistic reference image
   - user supplementary requests if present
