# PDF report redesign - implemented data only

The report now uses only values already produced or explicitly entered by the service.

## Page 1 - Summary
- fall prediction probability (`risk_score`)
- existing model decision text (`risk_level`)
- existing model threshold (`threshold_percent`)
- top positive SHAP contributors
- selected room
- number of actual improvement-priority hazard groups
- existing AI final summary

## Page 2 - Analysis
- positive SHAP contribution chart
- confirmed spatial hazard/problem priorities
- connected personal-risk factor text
- RAG vs AI-only source label
- optional user-entered room note

## Page 3 - Action plan
- selected solution for each priority hazard
- difficulty, estimated time, helper requirement, price note when actually generated
- expected effects when generated by the existing Action Plan flow
- deterministic Before/After 2D floorplan images
- checklist made from the user's selected solutions

## Deliberately not generated
- invented 5-level fall-risk scales
- per-room risk grades not computed by the backend
- fabricated fall-risk reduction percentages
- invented clinical interpretation
