# 배치/공간 분석 UI 분리 업데이트 (2026-08-19)

- 배치 평면도에 50cm 보조 그리드와 100cm 강조 그리드를 추가했습니다.
- 평면도 상단/왼쪽에 현재 방의 가로·세로 실제 치수를 표시합니다.
- `현재 배치 안전성 점검하기`를 누르면 배치 화면 아래에 결과를 붙이지 않고 별도의 `/layout_analysis` 페이지로 이동합니다.
- 분석 페이지에서 실제 분석이 실행되며 전체 화면 로딩 UI로 `배치 확인 → 위험 지점 분석 → 개선 방향 정리` 흐름을 보여줍니다.
- 분석 결과는 평면도와 우선 개선 내용을 2열로 정리하고, 작은 화면에서는 1열로 전환합니다.
- 분석 평면도 iframe은 내용 높이에 맞춰 자동 조절하고 내부 스크롤바를 숨겼습니다.
- 추가 확인 질문과 다음 단계 버튼도 분석 결과 페이지로 옮겼습니다.
- 배치 편집기의 기존 인라인 분석 결과/추천 모달은 제거했습니다.
