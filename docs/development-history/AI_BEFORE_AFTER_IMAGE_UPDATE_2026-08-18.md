# AI Before / After 이미지 생성 업데이트

## 변경 방향
- 최종 개선 결과의 중심을 단순 2D 평면도에서 **AI 생성 공간 Before / After 이미지**로 변경했습니다.
- 사용자가 만든 평면도는 버리지 않고 AI 이미지 생성의 기준(reference)으로 전달합니다.
- 개선안 설명도 함께 전달하여 After 이미지에 선택한 안전 개선사항을 적용합니다.

## 생성 순서
1. 현재 평면도를 좌표 기반 PNG로 렌더링합니다.
2. 해당 평면도를 이미지 입력으로 전달하여 현실적인 **Before 공간 이미지**를 생성합니다.
3. 생성된 Before 이미지를 다시 이미지 편집 입력으로 사용합니다.
4. 선택된 개선안 목록만 적용하도록 지시하여 **After 이미지**를 생성합니다.
5. 따라서 Before / After 간 카메라·가구·방의 전체 인상이 최대한 유지되도록 구성했습니다.

## UI
- Before: 현재 평면도 기반 AI 공간 이미지
- After: 동일 공간에 개선안을 반영한 AI 공간 이미지
- 우측: 개선 포인트 설명
- 하단 접기 영역: AI가 참고한 원래 평면도 및 개선 위치 평면도
- `다시 생성` 버튼 제공

## 주의
AI 생성 이미지이므로 실측 치수와 정확히 동일하다고 보장하지 않습니다. 좌표 기반 평면도는 계속 기준 자료로 유지됩니다.
