# V14 fixes — 2026-08-19

1. Clarification follow-up validator
- GPT temporary IDs such as AI_FALLBACK_001 are now recovered to the server-authoritative HZ_xxx instance using hazard code + fixed priority.
- GPT metadata mismatches (hazard code, rank, evidence IDs) are normalized to server-fixed values and recorded as warnings instead of surfacing raw validation errors to the user when recovery is unambiguous.

2. AI Before/After generation latency
- First generation now uses ONE image request to generate a wide Before/After pair and splits it into two PNGs locally.
- When Before is already cached, only After is edited in one image request.
- SDK retries remain disabled.
- Image request timeout is capped at 50 seconds by default (`OPENAI_IMAGE_MAX_SECONDS`).
- Browser abort timeout is 58 seconds.
- Removed multi-network fallback chains from the Before/After path.

3. PDF report image completeness
- PDF download buttons remain disabled until both AI Before and After images have completed.
- Backend `/api/download_report` returns 409 if both generated images are not ready.
- The report now includes BOTH generated Before and After images side by side, plus the deterministic improvement floorplan.
