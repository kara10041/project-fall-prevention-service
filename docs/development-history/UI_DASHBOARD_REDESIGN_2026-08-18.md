# 맞춤 공간 개선안 화면 리디자인

## 변경 내용
- Action Plan 최종 화면을 Before / After 평면도 비교형 대시보드로 재구성
- 사용자가 만든 현재 평면도(Before)를 서버에서 별도 렌더링하여 API로 반환
- 개선 평면도(After)는 기존 좌표 기반 번호/개선 아이콘 렌더링 유지
- 오른쪽 패널에서 평면도 번호와 개선안/대상 위치를 1:1로 연결
- 하단에 개선 포인트 요약 및 화면에서 확인할 수 있는 개선 효과를 카드형으로 표시
- 대안 변경 시 After 이미지만 즉시 다시 렌더링
- 기존 실행계획 선택, 난이도, 예상 소요시간, 가격 추정, 준비물/쇼핑 링크, PDF 다운로드 유지
- 추천 동선 표시는 추가하지 않음. 실제 현재 로직이 계산하지 않는 수치를 화면에서 임의로 제시하지 않음
