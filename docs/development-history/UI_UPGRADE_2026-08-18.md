# 공간 배치 UI 업그레이드 (2026-08-18)

1. 상단 맞춤 위험 체크리스트를 읽기 전용으로 변경하여 이전 단계의 응답이 이 화면에서 바뀌지 않도록 수정.
2. 가구 클릭 선택이 유지되도록 room click 이벤트를 수정하고, 선택 항목 삭제가 정상 동작하도록 개선.
3. 가구 리사이즈의 기존 320×220px 상한을 제거. 방 경계 안에서 최소 크기까지 자유롭게 축소/확대 가능.
4. 사각형/정사각형/원형 가구, 1/4원 문 모양, 선택 가구 90도 좌우 회전 기능 추가.
5. 출입구/단차/물기/주의영역을 방 안에 직접 표시하고 메모할 수 있는 공간 주석 기능 추가. 좌표·크기·메모를 backend floorplan의 spatial_annotations로 전달. 물기와 단차 표시는 각각 SLIPPERY_FLOOR, THRESHOLD_HIGH 명시 관찰값으로 연결.
6. 선택 항목의 X/Y 좌표, 실제 cm 크기, 가장 가까운 출입구까지의 거리를 즉시 표시.
7. 공간별 빠른 추가 프리셋 분리: 거실/침실/화장실/주방마다 다른 기본 가구 제공.
8. 저장/복원 데이터에 shape, rotation, annotations를 포함.
